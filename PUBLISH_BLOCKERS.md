# Publish Blockers

Current publishable status: resource kit, setup checklist, hidden-field map, sample normalizer, and QA scripts.

Do not position this as any of the following until separately built and tested:

- Jotform Marketplace app.
- Jotform API connector.
- OAuth integration.
- Webhook receiver.
- Automatic CRM sync.
- Consent-management or legal-compliance product.
- Managed storage or lead database.

Before marketplace or app-store submission, this needs:

1. Real Jotform account testing with an embedded form and native hidden fields.
2. Screenshots of hidden-field setup and sample submission review.
3. Confirmed Jotform Marketplace packaging requirements if the goal changes from resource kit to app listing.
4. Privacy-policy copy reviewed for the final data flow.
5. A clear support path for agencies using custom embed pages, multi-step forms, or CRM handoffs.
