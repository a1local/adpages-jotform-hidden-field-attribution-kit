# AdPages Jotform Hidden-Field Attribution Kit

Dependency-light setup kit for agencies adding UTM and click-id attribution to Jotform lead forms.

This is a manual resource kit, not a Jotform app. It does not call the Jotform API, does not use OAuth, does not create webhooks, and does not write form data anywhere. Use it to plan hidden fields, normalize sample submissions, and QA that attribution context survives the form submit path before building a real account-tested integration.

## What It Includes

- Hidden-field map for common Jotform lead attribution fields.
- Browser snippet for filling matching hidden fields from the current URL, referrer, and local first-touch hints.
- Sample Jotform-style submission input and deterministic normalized output.
- Local checks that verify required files, parse JSON, run syntax checks, and assert Jotform-specific safety claims.
- Smoke test that proves the sample submission maps UTMs, click IDs, landing page, referrer, first/last touch hints, consent, and source context.

## Intended Use

1. Add hidden fields to the target Jotform form using the names in `config/field-map.json`.
2. Add `snippets/utm-hidden-fields.js` to the page that embeds the Jotform form or adapt the field names to the local embed setup.
3. Submit a real test lead.
4. Compare the downloaded or copied submission payload against the output shape generated by `src/lead-attribution.mjs`.
5. Keep the output as a QA report or use it as a brief for the CRM/reporting integration that receives the form data later.

## Local Commands

```sh
npm --prefix integrations/jotform/adpages-hidden-field-attribution-kit run check
npm --prefix integrations/jotform/adpages-hidden-field-attribution-kit run smoke
```

## Scope Boundaries

This kit is safe to publish as setup documentation or a downloadable resource. It should not be described as a Jotform Marketplace app, API connector, webhook receiver, CRM sync, or consent-management product until those surfaces have been built and tested in a real Jotform account.

## Field Naming

The default hidden fields use simple Jotform question names:

- `utm_source`
- `utm_medium`
- `utm_campaign`
- `utm_term`
- `utm_content`
- `landing_page_url`
- `referrer_url`
- `gclid`
- `msclkid`
- `fbclid`
- `first_touch_summary`
- `first_touch_url`
- `last_touch_summary`
- `last_touch_url`
- `consent_status`
- `consent_source`
- `source_context`

Jotform may display question labels separately from question names. The normalizer reads Jotform-style `answers` objects by `name`, normalized label, and common raw request keys so the same sample works with copied export data or API-like JSON.
